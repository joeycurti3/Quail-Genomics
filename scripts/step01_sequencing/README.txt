The following files/scripts are in this directory: 

1. step01_a_CAQU_checkMD5sums_20220927.sh - Check MD5 sums of downloaded sequencing data
2. step01_b_CAQU_wgetRefGen_20221103.sh - Download reference genome GCA_023055505.1_bCalCai1.0.p
3. step01_c_CAQU_RefGenDict_GCA_023055505.1_bCalCai1.0.p_20220927.sh - Generate a dictionary file for the downloaded reference genome
4. step01_d_CAQU_catMultiLaneData_20240403.sh - Concatenate multi-lane fastq files into one forward and one reverse file
